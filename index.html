Projects

Infrastructure and network modernisation

Topline Limited, Port Harcourt · 106 users · 5 locations

The problem

The company ran on a very basic network. There was no server, no Active Directory, no file server, no structured cabling, no monitoring, and no consistent way to onboard new systems. Users and PCs were managed one by one. The network suffered frequent downtime and poor performance.

What I did

  • Built the network infrastructure and introduced Windows Server and Active Directory for central management of users and PCs
  • Set up a file server for shared work files
  • Implemented 4 VLANs on MikroTik and Ubiquiti UniFi equipment, separating staff, VoIP, CCTV, and interns and guests
  • Deployed 8 access points, fibre connectivity and structured cabling across the Base Yard, Corporate Office and 3 remote locations
  • Standardized new-user provisioning and PC configuration, documented in SOPs

Result

  • Centralized user and endpoint administration for 106 users
  • Network uptime improved to 97% and performance to 95%, up from frequent downtime and poor performance
  • Upgraded connectivity and expanded network coverage across all 5 locations
  • Repeatable onboarding of new users and PCs using documented procedures

Windows Server, Active Directory, Group Policy, MikroTik, Ubiquiti UniFi, VLANs, DNS, DHCP

Microsoft 365 and SharePoint Online rollout

Topline Limited · 15 departments

The problem

Teams shared files only through the on-premises file server, so there was no remote access and no cloud sharing. The company later adopted Microsoft 365 Business Basic and OneDrive, but the licences were underused.

What I did

  • Proposed and led the introduction of SharePoint Online
  • Designed sites for 15 departments, with folder structures built around how each team works, and linked files across sites where processes overlap
  • Managed the security and governance side: permission structure and access control, SharePoint group membership, and document access restrictions
  • Assigned site owners and departmental ownership so each team looks after its own site
  • Planned the migration approach from the file server to the cloud
  • Trained users and drove adoption
  • Assessed external sharing considerations and set access accordingly

Result

  • 15 departments collaborating on structured sites, with access from outside the office
  • Better use of licences the company already paid for
  • Files that are easier to find and processes that are easier to follow

SharePoint Online, OneDrive, Microsoft 365, Entra ID, Teams

Odoo ERP rollout: testing, onboarding and support

Topline Limited · 74 users across all departments

The problem

The business needed one ERP for processes that cross departments. After development, it had to be verified against the contract and rolled out with the right access for each person.

What I did

  • Tested every module after development and confirmed it was active and responding
  • Checked that every feature in the contract was delivered
  • Registered all users and assigned them to roles and groups
  • Limited access to the 74 staff with interdepartmental responsibilities
  • Supported users after launch and onboard every new joiner by role

Result

  • 74 users working in the system with role-based access
  • Delivered features verified against the contract
  • A repeatable onboarding process for new staff

Odoo ERP, user and role administration, acceptance testing, user support
